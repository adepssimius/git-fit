**Two things this costs, both worth watching:**

- **Wednesday's uphill threshold now sits two days off a 213min long run instead of three.** It
  is the exposed session of the week. Tuesday's night run is a kit shakedown and low-intensity,
  so it absorbs the change fine. This week only runs 268-288min because the trip cuts it, so
  there is real slack — but if anything gets trimmed, trim Wednesday's rep count, not its volume.
- **Lower A falls the morning after the long run.** `rules/strength-authoring.md` wants Lower A
  farthest from the long run; this is the closest it can get. Strength is best-effort
  (`athlete/profile.md` § "Priority when time is short"), so this week is deliberately NOT being
  re-authored around it — but it is the first lift to drop if the week compresses.
