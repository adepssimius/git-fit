## Saturday — decided, and the reasoning is worth keeping

Athlete asked whether to run the 50k Saturday night or Sunday night for an extra recovery day.
**Saturday, confirmed 2026-09-11.**

**The deciding argument: it is not +1 recovery day, it is a swap.** Both versions finish ~00:30.
Run Saturday and the recovery day is **Sunday, which is free**. Run Sunday and it is **Monday,
which is a work day**, on 4-5 hours of sleep after a 50k. Net recovery is about the same; where it
lands is much worse.

Three things behind that:

1. **The precedent is in this log and it cost him.** 09-06 was a Sunday-night run finishing 00:41
   — into Labor Day, so he *had* the Monday. He ran 22.6km on it anyway and was red with soreness
   7 by Tuesday. Monday 09-14 is an ordinary work day. Same shape, bigger session, no holiday.
2. **Block week 15 starts Monday** with 415min planned, including 09-16's track session. Starting
   it off a 50k that ended at 00:30 that morning compromises the front half of the week.
3. **Thursday is already far enough back.** By 17:25 Saturday it is ~55 hours since that run
   ended — ample for an easy 2-hour effort at RPE 3. The real load is Monday's 22.6km, five days
   gone either way, so the extra 24 hours buys very little.

**The condition that would change it:** a red reading tomorrow morning — sleep collapse, soreness
spike, the knee returning. In that case the session moves to next weekend or shortens. **It does
not move to Sunday night**, which is the one option that pays for itself out of the working week.
